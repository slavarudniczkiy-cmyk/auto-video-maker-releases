# Наша музыка

Треки из этой папки программа Auto Video Maker показывает во вкладке «Наша музыка» (кнопка «Библиотека музыки» в разделе «Фоновая музыка»). Скачать их может каждый, у кого стоит программа.

## Как добавить трек

1. Вверху этой страницы нажмите **Add file**, затем **Upload files**.
2. Перетащите файлы MP3, M4A, WAV, OGG или FLAC, до 25 МБ каждый.
3. Нажмите зелёную кнопку **Commit changes**.

В программе нажмите «Обновить список» во вкладке «Наша музыка», и трек появится.

## Настроение в названии

Чтобы кнопка «Подобрать музыку» знала, в какую часть ролика ставить трек, допишите настроение в квадратных скобках:

```
Ночной город [мрачная].mp3
Утро в горах [спокойная, светлая].mp3
```

Настроения: спокойная, светлая, мрачная, напряжённая, загадочная, весёлая, эпичная. Трек без скобок можно добавить в ролик только вручную.

## Важно

- Папка открытая: любой может скачать отсюда файлы.
- Кладите сюда только музыку, которую разрешено раздавать: свою или с открытой лицензией вроде CC0 и CC BY. Треки из фонотеки YouTube, из CapCut и из чужих роликов сюда класть нельзя: их можно ставить в свои видео, но не раздавать файлами.
- Если лицензия трека требует указать автора (как CC BY), впишите автора в описание ролика сами: для этой папки программа его не знает.
- Чтобы убрать трек, откройте его, нажмите «…» справа вверху и выберите **Delete file**.
