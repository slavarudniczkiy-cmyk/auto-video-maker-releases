# Auto Video Maker

## Что это за программа

Auto Video Maker сам собирает длинный ролик для YouTube из ваших картинок и озвучки. Вы даёте ему папку с картинками, файл озвучки и тайминг (какая картинка на какой фразе), нажимаете «Автомонтаж», и через несколько минут получаете готовый MP4.

- **Тайминг** можно дать файлом субтитров (SRT, VTT), текстом, таблицей Excel или CSV. Можно вообще без него: программа сама распознает озвучку и разрежет её по паузам на сцены (в первый раз она докачает модель распознавания речи).
- **Озвучка** может быть одним файлом или несколькими кусками, программа склеит их по порядку.
- **Картинки оживают**: плавные наезды, отъезды и панорамы камеры, объёмный 2.5D-эффект, красивые переходы между сценами, размытый фон под вертикальными и узкими картинками.
- **Для удобства зрителя**: субтитры по фразам, заставки глав, быстрый наезд камеры на выбранной фразе.
- **Живой просмотр**: ролик можно посмотреть целиком прямо в программе до экспорта.
- **Экспорт** в MP4 (быстро на видеокартах NVIDIA) или набор файлов, чтобы доделать ролик в CapCut.
- **Обновляется сама**, новые версии приходят без повторной установки.

## Как установить Auto Video Maker

1. Скачайте файл **Auto-Video-Maker-Setup-….exe** (около 180 МБ): внизу этой страницы в разделе **Assets**, или по ссылке https://github.com/slavarudniczkiy-cmyk/auto-video-maker-releases/releases/latest
2. Запустите его. Если Windows покажет синее окно «Система Windows защитила ваш компьютер», нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**. Так Windows встречает любую программу без платной цифровой подписи.
3. Нажимайте «Далее» и «Установить». В конце программа запустится сама, ярлык появится на рабочем столе и в меню «Пуск».

## Обновления

Второй раз ничего скачивать не нужно. Программа сама скачивает новые версии, а справа вверху, рядом с шестерёнкой настроек, появляется кнопка «Обновить до …». Если её не нажимать, обновление поставится само, когда вы закроете программу.

## Если установка не получилась

**Ошибка «Извлечение: ошибка записи файла … WinShell.dll».** Так было в старых версиях: скачайте установщик заново по ссылке выше, в новых этой ошибки нет. Если он уже показал эту ошибку, нажмите OK: программа к этому моменту уже установлена. Нажмите Win+R, вставьте строку ниже и нажмите Enter:

```
%LOCALAPPDATA%\Programs\Auto Video Maker\Auto Video Maker.exe
```

**Другая ошибка записи файла или «нет доступа».** Обычно файл не даёт записать антивирус. Приостановите его на время установки (или добавьте установщик в исключения) и запустите установщик ещё раз. Проверьте, что на диске C: свободно хотя бы 1 ГБ.

**Установщик вообще не открывается.** Нажмите на файл правой кнопкой, выберите «Свойства», поставьте галочку «Разблокировать» и нажмите OK.

## Что нужно для работы

Windows 10 или 11, 64-битная. Видеокарта NVIDIA ускоряет экспорт, но без неё программа тоже работает.
